# قهوة المعلّم ☕

لعبة متصفح ثلاثية الأبعاد: إنت المعلّم في قهوة بلدي، بتحضّر الشيشة للزباين قبل ما صبرهم يخلص.

## إزاي تلعب
1. دوس على زبون من فوق.
2. هات المعسّل اللي طالبه من على الرف.
3. دوس وامسك عشان ترص الحجر، وسيب في المنطقة الخضرا.
4. خرّم القصدير.
5. حط الفحم وهو مولّع (أحمر).
6. دوس على الزبون عشان القهوجي يقدّمله الشيشة.

## التشغيل
- افتح `index.html` في أي متصفح حديث (محتاج إنترنت عشان مكتبة three.js).
- لو المتصفح مش بيدعم الـ 3D، اللعبة بتشتغل تلقائيًا بنسخة 2D.

## النشر على GitHub Pages
Settings ← Pages ← Source: `main` / root، وبعدها اللعبة هتبقى على:
`https://<اسم-المستخدم>.github.io/<اسم-الريبو>/`

## التقنيات
- HTML/CSS/JavaScript في ملف واحد.
- three.js r160 (من jsDelivr) للمشهد الثلاثي الأبعاد.
- Web Audio للمؤثرات، وتسجيلات صوتية حقيقية للقهوجي.
