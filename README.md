# جدوى المحاكاة (G-Adwa) — منصة المحاكاة العربية

موقع https://www.g-adwa.com: محاكيات تفاعلية لتجربة المشاريع والقرارات والعمليات.

- `index.html` الصفحة الرئيسية، `tools.html` الأدوات، `guides/` المقالات
- `g-adwa-sim.html` محاكي الاستثمار، `Coffe-Shop.html` لعبة قهوة المعلّم
- `Cap-machine-3d.html` مجسم 3D، `Medical_Analysis.html` بحث مناقصات نوبكو
- كود AdSense موجود فقط في صفحات المحتوى (وليس صفحات الأدوات/الألعاب)
